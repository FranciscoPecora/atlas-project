# Data dictionary: ledger_public.parquet

One row per event extracted from a daily report. Generated by `make release`
from `src/release.py`; the JSON Schema is `ledger_public.schema.json`.

The file holds no text from the reports: the evidence is given as character
offsets into the cleaned report text, with that text's SHA-256 and the report
URL. Rebuild the cleaned text with `make data` and check the hash to read it.

| Field | Type | Meaning |
| --- | --- | --- |
| `event_id` | string | Stable id: report id, system, index in the report |
| `report_id` | string | Source and report date, e.g. gsu-2026-08-01 |
| `source` | string | gsu (Ukrainian General Staff), af (Ukrainian Air Force), rumod (Russian Ministry of Defence Telegram channel) or isw |
| `report_date` | date | Publication date of the report |
| `event_date` | date | Date the event happened (default: report date - 1) |
| `event_type` | EventType | One of 12 types (annotation guideline) |
| `epistemic_status` | EpistemicStatus | Who asserts the event, and how |
| `actor` | Side or null | Side that acted: RU, UA or other |
| `target` | Side or null | Side acted upon |
| `geo_precision` | integer or null | 1 settlement, 2 area/direction, 3 oblast |
| `quantity` | integer or null | Count stated in the report, if any |
| `gazetteer_id` | string or null | gn:<GeoNames id> or osm:<OSM node id> |
| `place_name` | string or null | Standard name from the gazetteer (Latin) |
| `oblast` | string or null | Oblast of the gazetteer place |
| `lat` | number or null | Latitude from the gazetteer, never the model |
| `lon` | number or null | Longitude from the gazetteer, never the model |
| `cluster_id` | integer or null | Rule 7a duplicate cluster |
| `cluster_size` | integer or null | Events in that cluster |
| `confirmed_by` | string or null | Rule 7b: event_id of the confirmation |
| `lag_days` | integer or null | Rule 7b: report days from claim to confirm |
| `evidence_start` | integer | Start offset of the evidence in the cleaned text |
| `evidence_end` | integer | End offset (exclusive) |
| `text_sha256` | string | SHA-256 of the cleaned report text the offsets index |
| `source_url` | string | URL of the report (rumod: of the channel post) |
| `system` | string | Pipeline version that produced the row, e.g. S3-H |
| `run_id` | string | Run that produced the row |
